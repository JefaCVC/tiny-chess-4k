A 4 KB Python chess engine: 0x88 board, negamax with alpha-beta, quiescence,
transposition table, tapered piece-square eval and a per-scenario
mate book. Fixed node budget per move — fully deterministic.

Built for the [make.fun](https://make.fun) `tiny-chess-01` bounty.
